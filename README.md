# Frontiers TCG

Este repositório hospeda os arquivos e imagens do **Frontiers TCG**, permitindo que o jogo seja lido e jogado diretamente através da plataforma TCG Arena. 

> **Nota sobre uso:** Você é livre para baixar as imagens das cartas disponíveis aqui para usos pessoal, desde que seja para uso **estritamente não comercial** (o repositório já conta com um arquivo LICENSE para mais detalhes).

---

## Como Instalar

Para adicionar o Frontiers TCG à sua conta do TCG Arena, o processo é automático:

1. Clique no link de instalação: [Adicionar Frontiers TCG](https://tcg-arena.fr/load/aHR0cHMlM0ElMkYlMkZmcm9udGllcnN0Y2cuZ2l0aHViLmlvJTJGRnJvbnRpZXJzLVRDRy1BcmVuYSUyRkZyb250aWVyc19UQ0cuanNvbg==)
2. Na página que se abrir, clique no botão **"Add Game"**.

---

## Como Montar um Deck

Com o jogo adicionado, você já pode construir seus baralhos:

1. Acesse a aba **Decks**.
2. Clique em **Create Deck**.
3. Digite um nome para o seu baralho e selecione o formato do jogo.
4. Clique novamente em **Create Deck** para confirmar.
5. Monte sua estratégia selecionando as cartas desejadas.
6. Ao finalizar, clique em **Save**.

---

## Como Jogar

Para iniciar uma partida contra seus amigos ou outros jogadores:

1. Acesse a aba **Play**.
2. Encontre seu oponente escolhendo uma das opções de conexão:
   * **Direct Connect:** Use o código de amigo para jogar com alguém específico.
   * **Public Lobbys:** Entre em uma sala aberta para jogar online contra qualquer um.
   * **Matchmaking:** Busque uma partida aleatória.
3. No lado esquerdo da tela, clique no botão **"Start a New Game"**.
4. Selecione o deck que você acabou de montar (ou escolha um deck estrutural pré-montado).
5. Clique em **OK** e boa partida!
